---
name: prompts-on
description: Nyalakan lagi pencatatan prompts-log di repo ini setelah dimatikan dengan /prompts-off.
---

1. Jalankan `git config --unset prompts-log.off` di repo ini.
2. Laporkan ke user: mulai giliran berikutnya, prompt di repo ini dicatat lagi ke `docs/prompts/`. Prompt selama
   dimatikan bisa diisi dengan `/prompts-backfill`.
