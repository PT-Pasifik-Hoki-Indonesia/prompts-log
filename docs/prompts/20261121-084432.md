Pembatasan itu keputusan awal saat plugin dibuat, untuk menjaga dua hal:

- **Tidak bocor ke tempat yang salah.** Entri langsung di-stage, jadi ikut ter-commit tanpa disadari. Kalau seseorang memasang plugin lalu mengerjakan repo pribadi, repo klien, atau repo open source orang lain, isi percakapannya dengan AI akan ikut ter-push ke sana. Isinya bisa saja menyebut nama internal, URL server, atau rahasia yang tidak tersamarkan.
- **Tujuannya standar kantor.** Backup harian ke Drive juga hanya mengambil repo milik org, jadi entri dari repo lain tidak berguna untuk keperluan itu.

Jadi batasnya bukan soal teknis, tapi pengaman supaya plugin hanya aktif di tempat yang memang dimaksud. Opt-in per repo tetap menjaga pengaman itu, tapi repo di luar org juga bisa ikut tercatat kalau sengaja diaktifkan.
