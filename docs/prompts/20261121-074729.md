A. Install Claude Code (sekali per komputer)

Syarat: langganan Claude Pro, Max, Team, atau Enterprise (plan gratis tidak bisa memakai Claude Code), Git, dan Python 3.

A.1 macOS (versi 13 ke atas)

Buka Terminal, lalu jalankan:

curl -fsSL https://claude.ai/install.sh | bash

Kalau lebih suka Homebrew: brew install --cask claude-code. Versi ini tidak update otomatis, jadi sesekali jalankan brew upgrade claude-code.

Cek Python dan Git dengan python3 --version dan git --version. Kalau belum ada, macOS akan menawarkan untuk menginstalnya.

A.2 Windows (10 versi 1809 ke atas)

1. Install Git for Windows dari https://git-scm.com/downloads/win. Ini wajib untuk plugin ini, karena hook-nya dijalankan lewat Git Bash.
2. Install Python 3 dari https://www.python.org/downloads/. Saat menginstal, centang Add python.exe to PATH.
3. Buka PowerShell biasa (bukan Run as Administrator), lalu jalankan:
irm https://claude.ai/install.ps1 | iex
   Kalau yang terbuka CMD, pakai perintah ini:
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
4. Buka Git Bash, lalu jalankan python3 --version. Kalau muncul command not found, plugin ini belum bisa jalan di komputer itu. Kabari saya, karena perintah hook-nya perlu saya sesuaikan untuk Windows.

A.3 Cek dan login (Mac dan Windows)

Buka terminal baru, lalu jalankan:

claude --version
claude

Perintah claude akan membuka browser untuk login. Kalau claude tidak dikenali, tutup terminal lalu buka lagi. Kalau masih belum bisa, jalankan claude doctor.

Catatan untuk pengguna extension VS Code: extension itu tidak memasang perintah claude di terminal. Langkah A.1 atau A.2 tetap perlu dijalankan.

B. Pasang plugin (sekali per komputer)

Di terminal mana pun (terminal VS Code juga bisa):

claude plugin marketplace add PT-Pasifik-Hoki-Indonesia/prompts-log
claude plugin install prompts-log@psg
claude plugin list

Pastikan prompts-log@psg tampil dengan status enabled. Plugin ini otomatis aktif di semua repo org, di semua branch, dan juga di extension VS Code serta aplikasi desktop di komputer itu.

Setelah memasang, tutup semua sesi Claude Code yang masih terbuka, lalu buka sesi baru.

C. Supaya riwayat prompt tidak terhapus (sekali per komputer)

Claude Code menghapus riwayat sesi setelah 30 hari. Buka file berikut:
- Mac: ~/.claude/settings.json
- Windows: %USERPROFILE%\.claude\settings.json

Lalu tambahkan baris ini di dalam kurung kurawal paling luar:

"cleanupPeriodDays": 3650,

D. Isi riwayat lama (sekali per repo, oleh tiap orang yang pernah mengerjakannya)

1. Buka sesi Claude Code di folder repo project.
2. Ketik /prompts-backfill.
3. AI akan menulis:
   - 📝 entri asli dari riwayat sesi di komputer Anda,
   - 🤖 entri sintesis untuk commit yang riwayat sesinya sudah tidak ada. Isinya prompt dan spesifikasi hasil yang disusun dari isi commit.
4. Kalau commit-nya banyak, AI akan bertanya mau dikerjakan semua atau sebagian dulu.
5. Commit prompts.md dan .gitattributes.

E. Kerja sehari-hari: otomatis

1. Kerja dengan Claude Code seperti biasa. Setiap kali AI mengubah file, entri baru ditambahkan ke prompts.md dan langsung di-stage.
2. Commit secara manual, dari VS Code atau terminal. Stage file kode yang diubah. prompts.md sudah staged, jadi ikut otomatis dalam commit yang sama. Git hook mengubah status entri jadi 📦 sudah di-commit.
3. prompts.md dianggap final setelah masuk branch utama. Dari sana, salinannya di-backup ke Drive setiap hari.

F. Update plugin

claude plugin marketplace update psg
claude plugin update prompts-log@psg

Setelah update, tutup sesi lama dan buka sesi baru. Sesi yang dibuka sebelum update bisa gagal mencatat.
